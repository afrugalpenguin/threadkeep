# threadkeep-server

Local web UI for Threadkeep: browse, search and replay your archived conversations. It binds 127.0.0.1 only and is started with `threadkeep ui`.

See the [Threadkeep README](https://github.com/afrugalpenguin/threadkeep#readme) to get started, [docs/usage.md](https://github.com/afrugalpenguin/threadkeep/blob/main/docs/usage.md) for every command and [docs/privacy.md](https://github.com/afrugalpenguin/threadkeep/blob/main/docs/privacy.md) for the privacy notes.
