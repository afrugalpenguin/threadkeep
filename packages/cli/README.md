# hansard

Command line for Hansard. Run `hansard doctor` to check your setup.

`hansard ui` serves the local web UI on 127.0.0.1 (`--port` to choose the port, `--open` to launch a browser).

See the [Hansard README](https://github.com/afrugalpenguin/hansard#readme) to get started, [docs/usage.md](https://github.com/afrugalpenguin/hansard/blob/main/docs/usage.md) for every command and [docs/privacy.md](https://github.com/afrugalpenguin/hansard/blob/main/docs/privacy.md) for the privacy notes.
